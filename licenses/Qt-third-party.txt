Third-party code in the Qt modules Saylight ships
==================================================

Saylight ships these Qt 6.12 modules from PySide6-Essentials: Qt Core, Qt GUI, Qt Widgets and Qt Network,
with the plugins qwindows (platform), qico (image format), qnetworklistmanager (network information) and
qmodernwindowsstyle (style). Qt itself is used under the LGPL-3.0 (see LGPL-3.0.txt and GPL-3.0.txt).

Qt lists the following third-party code for these modules in "Licenses Used in Qt" for Qt 6.12:
https://doc.qt.io/qt-6/licenses-used-in-qt.html
Qt Widgets has no entries of its own. Some entries apply only to other platforms; they are kept so the list
matches Qt's. The copyright lines and the full licence text of each entry are in the Qt 6.12.0 source
archive (qt_attribution.json and the LICENSES folder of qtbase):
https://download.qt.io/official_releases/qt/6.12/6.12.0/
Qt's Software Bill of Materials for 6.12 gives the same list as SPDX 2.3 data.
